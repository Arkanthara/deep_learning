## Understand the problem

A linear classifier can fail in the original space yet succeed after transforming the data. A feature map Φ changes the problem’s geometry. The model remains linear in Φ(x), but its boundary can be nonlinear in x.

## How it works

For XOR, adding the product of the two coordinates is enough to construct a separator. Polynomials similarly use powers of x as features. Descriptors such as HOG introduce signal knowledge. Kernels compute inner products between representations without necessarily constructing them explicitly; deep networks learn the representations.

$$
f(x)=\sigma(w^\top\Phi(x)+b),\qquad\kappa(x,x^\prime)=\Phi(x)^\top\Phi(x^\prime)
$$

## Develop the reasoning

A feature map chooses what should become simple. For a radial task, replacing (x₁,x₂) with radius removes irrelevant angular variation; for another task it would destroy required information. A kernel does not eliminate this choice: it expresses it implicitly through similarity. For example, a polynomial kernel contains coordinate interactions. Learned representations shift some of this work to data and optimisation, but remain constrained by architecture and loss.

## Worked example

For binary inputs, the score x₁ + x₂ − 2x₁x₂ − 0.5 is positive only for (0,1) and (1,0). It is affine in the representation (x₁,x₂,x₁x₂).

## Understanding check

The class depends only on whether x₁²+x₂² > 1. Which feature permits a simple linear decision?

<details>
<summary>Reveal the worked answer</summary>

Choose Φ(x)=x₁²+x₂² and compare Φ(x) with 1. A circular boundary in the original space becomes a threshold in one dimension.
