## Understand the problem

The gradient collects partial derivatives of a loss with respect to parameters. It indicates the direction of steepest local increase in Euclidean geometry. To decrease the loss, take a small step in the opposite direction.

## How it works

The learning rate η controls step size. Too small is slow; too large can oscillate or diverge. The argument relies on a local approximation: a descent direction does not guarantee a decrease for an arbitrarily large move. For networks, nonconvexity generally prevents guarantees of a global minimum.

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta\mathcal L(\theta_t)
$$

## Develop the reasoning

The local expansion $L(\theta+\Delta)\approx L(\theta)+\nabla L(\theta)^\top\Delta$ explains the negative update sign. With $\Delta=-\eta\nabla L$, first-order change is $-\eta\|\nabla L\|^2$. Higher-order terms can dominate if the step is too large. For $L(w)=(w-a)^2$, error evolves exactly as $w_{t+1}-a=(1-2\eta)(w_t-a)$. Convergence here requires $0<\eta<1$; the threshold depends on curvature.

## Worked example

For L(w) = (w−3)², w = 0 gives gradient −6. With η = 0.1, the next w is 0.6 and the loss falls from 9 to 5.76.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

w = torch.tensor(0., requires_grad=True)
for step in range(5):
    loss = (w - 3).square()
    loss.backward()
    with torch.no_grad():
        w -= 0.1 * w.grad
    w.grad = None
    print(step, w.item())
```
