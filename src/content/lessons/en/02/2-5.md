## Understand the problem

An embedding represents observations in a new space. The course introduces k-means, which summarises data with prototypes, and principal component analysis, which finds a low-dimensional affine subspace. Both use squared error, but they produce different representations.

## How it works

K-means alternates nearest-centroid assignment and mean recomputation. PCA centres the data and keeps directions of greatest variance, obtained by eigendecomposition or SVD. Projection minimises reconstruction error among subspaces of fixed dimension. These representations remain limited for complex nonlinear variation.

$$
\hat x=\bar x+V_kV_k^\top(x-\bar x)
$$

## Develop the reasoning

For k-means, nearest-centroid assignment minimises error with centroids fixed. With assignments fixed, the mean minimises a group’s squared-distance sum. Alternation therefore cannot increase this objective, but may reach a local optimum. For PCA, centring isolates the mean; dominant covariance eigenvectors define retained orthogonal directions. Component count controls a reconstruction tradeoff. Neither k-means nor PCA automatically uses labels: geometric groups need not be classes.

## Worked example

An MNIST image becomes a vector of 784 values. PCA with 20 components represents it with 20 coordinates and reconstructs it using the mean and 20 directions; k-means associates it with a prototype.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

X = torch.tensor([[1., 2.], [2., 4.], [3., 6.]])
mean = X.mean(dim=0, keepdim=True)
centered = X - mean
U, S, Vh = torch.linalg.svd(centered, full_matrices=False)
V = Vh[:1].T
coordinates = centered @ V
reconstruction = coordinates @ V.T + mean
print(reconstruction)
```

## Understanding check

Two PCA components explain variances 9 and 1. What fraction of variance does retaining only the first preserve?

9/(9+1)=90%. This is a fraction of geometric variance, not a guarantee of retaining 90% of information useful for classification.
