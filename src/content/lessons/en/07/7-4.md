## Understand the problem

A VAE defines a generative model: draw z from a prior, then x from a probabilistic decoder pθ(x|z). The likelihood pθ(x) requires an often intractable integral. An encoder qφ(z|x) approximates the posterior and makes it possible to optimise a lower bound, the ELBO.

## How it works

The ELBO combines expected probabilistic reconstruction with a KL divergence between approximate posterior and prior. KL connects codes to a distribution we can sample from. With a diagonal Gaussian encoder, reparameterisation z = μ + σ⊙ε separates random noise from differentiable parameters. Maximising the ELBO means minimising its negative, typically sampling one z per example.

$$
\mathrm{ELBO}(x)=\mathbb E_{q_\phi(z|x)}[\log p_\theta(x|z)]-D_{KL}(q_\phi(z|x)\|p(z))
$$

## Develop the reasoning

The identity $\log p_\theta(x)=\mathrm{ELBO}(x)+D_{KL}(q_\phi(z|x)\|p_\theta(z|x))$ explains the bound: the remaining KL is nonnegative. For a diagonal Gaussian posterior and standard normal prior, its penalty is $\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2)$. Reconstruction depends on the chosen decoder: fixed-variance Gaussian gives scaled squared error; Bernoulli gives binary log likelihood. Sums and means across pixels, latent dimensions and batches must be balanced consistently.

## Worked example

For q = N(0,I) and p = N(0,I), KL is zero. If μ moves away from zero without improving reconstruction, the penalty increases. log_var represents log σ², so exp(log_var/2) is needed to obtain σ.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

mu = torch.zeros(4, 8, requires_grad=True)
log_var = torch.zeros(4, 8, requires_grad=True)
eps = torch.randn_like(mu)
z = mu + torch.exp(0.5 * log_var) * eps
kl_per_sample = 0.5 * (
    mu.square() + log_var.exp() - 1 - log_var
).sum(dim=1)
print(z.shape, kl_per_sample)
```
