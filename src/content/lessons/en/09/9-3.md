## Understand the problem

To see which regions influence a prediction, mask areas and measure score changes. This occlusion analysis is intuitive but expensive and depends on the mask. Another approach differentiates a class score with respect to pixels: the gradient indicates local sensitivity.

## How it works

SmoothGrad averages gradients over slightly noisy inputs to reduce some irregularities. Deconvolution-style and guided-backpropagation visualisations change the propagation rule through ReLU, so they are not ordinary gradients. Grad-CAM weights convolutional feature maps by their spatially averaged gradients to construct a coarse class-related map.

$$
\alpha_k^c=\frac1{HW}\sum_{i,j}\frac{\partial s_c}{\partial A_{ij}^k},\qquad L^c=\operatorname{ReLU}\!\left(\sum_k\alpha_k^c A^k\right)
$$

## Develop the reasoning

For small perturbation δ, the gradient supports $s_c(x+\delta)-s_c(x)\approx\nabla_xs_c(x)^\top\delta$. A large coefficient indicates possible local change, not necessarily concept presence. Grad-CAM performs this analysis in a chosen spatial layer; its resolution depends on that map. A deep map may be coarse and an early one less semantic. Compare methods with identical inputs, targets and normalisation, and verify effects of actual applied perturbations.

## Worked example

For maps A₁ and A₂ with gradient weights 0.7 and −0.2, Grad-CAM is ReLU(0.7A₁−0.2A₂), then can be upsampled for overlay on the image.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch
from torch import nn

model = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 2))
model.eval()
x = torch.randn(1, 4, requires_grad=True)
score = model(x)[0, 1]
(gradient,) = torch.autograd.grad(score, x)
print(gradient)  # local sensitivity of class 1 to the input
```

## Understanding check

A pixel gradient is −2. Under the local approximation, increasing that pixel by 0.01 changes the score by how much?

<details>
<summary>Reveal the worked answer</summary>

Approximately −0.02, if other pixels stay fixed and the perturbation is small enough for the approximation.
