## Understand the problem

An nn.Module describes architecture; an autograd.Function defines an operation with a custom derivative. forward and backward are static methods. Calling apply connects the operation to the differentiation graph.

## How it works

The context stores required values, notably through save_for_backward. backward receives output sensitivity and must return a contribution for each input, or None for a nondifferentiable input. gradcheck compares results with finite differences; double-precision inputs away from nondifferentiable points are generally used.

$$
\mathrm{backward}(v)=J_f(x)^\top v
$$

## Develop the reasoning

Backward’s contract is multiplication by the transposed Jacobian. With multiple inputs, return one same-shaped gradient for each in order, and None for nondifferentiable arguments. Required intermediate values must be saved without later mutation. `gradcheck` numerically perturbs inputs and compares changes; double precision, suitable tolerances and regular points avoid confusing rounding or nondifferentiability with a bug. Higher-order derivatives require an implementation retaining the necessary dependencies itself.

## Worked example

For an operation y = x², backward must return grad_output × 2x. Returning only 2x would ignore the loss dependency through computations after y.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

class Square(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x.square()

    @staticmethod
    def backward(ctx, grad_output):
        (x,) = ctx.saved_tensors
        return grad_output * 2 * x

x = torch.randn(3, dtype=torch.double, requires_grad=True)
print(torch.autograd.gradcheck(Square.apply, (x,)))
```

## Understanding check

For f(u,v)=uv, which pair must backward return given incoming gradient g?

(g×v, g×u), with required reductions if broadcasting occurred. Each final gradient must match its input’s shape.
