## Understand the problem

In multiclass classification, the network produces logits: unnormalised real scores. Softmax transforms them into positive probabilities summing to 1. Maximising the correct class probability is equivalent to minimising its negative logarithm, cross-entropy with a categorical target.

## How it works

CrossEntropyLoss takes logits directly and stably combines log-softmax with negative log likelihood. For integer targets, each target is a class index. For one example, the gradient with respect to a logit is the predicted probability minus the correct-class indicator.

$$
\ell(z,y)=-z_y+\log\sum_k e^{z_k},\qquad\frac{\partial\ell}{\partial z_k}=\operatorname{softmax}(z)_k-\mathbf1_{k=y}
$$

## Develop the reasoning

Softmax is invariant to adding the same constant to every logit. Their maximum is therefore often subtracted before exponentiation to prevent overflow. For loss $-z_y+\log\sum_k e^{z_k}$, differentiating the first term gives −1 for the true class and 0 elsewhere; differentiating the second gives softmax probabilities. This derivative pushes the correct logit up and the others down. Batch averaging adds a factor 1/B.

## Worked example

If the true class receives probability 0.8, the loss is −ln(0.8) ≈ 0.223. At 0.1, it is about 2.303: a confident error is heavily penalised.

## Understanding check

Predicted probabilities are (0.2, 0.3, 0.5), and the first class is correct. What is the logit gradient?

<details>

For one example the gradient is (−0.8, 0.3, 0.5). Subtracting it raises the first logit and lowers the other two.
