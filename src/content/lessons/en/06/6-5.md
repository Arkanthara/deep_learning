## Understand the problem

A residual block learns a correction F(x) added to the input. It can approximate the identity simply by making that correction small. This builds on highway networks, where a gate controlled how much signal was transformed or passed through directly.

## How it works

The block derivative contains an identity term, providing a direct route for signal and gradient. Both branches need compatible shapes; changing resolution or channel count may require a projection, often a 1×1 convolution. Preactivation variants move normalisation and activation to preserve a more direct identity path. Stochastic depth temporarily drops residual branches.

$$
y=x+F(x),\qquad\frac{\partial y}{\partial x}=I+J_F(x)
$$

## Develop the reasoning

Given sensitivity g at y=x+F(x), x receives $g+J_F(x)^\top g$. If F’s derivative is small, the direct contribution remains close to g. A projection P replaces identity when dimensions differ, giving y=Px+F(x) and gradient $P^\top g+J_F^\top g$. That shortcut is no longer an exact identity. Residual addition differs from U-Net concatenation: concatenation keeps channels separate and changes their count.

## Worked example

If a block should preserve an already useful representation, learning F(x) ≈ 0 is natural. If the input has 16 channels and F(x) produces 32, the shortcut branch must be adapted before addition.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch
from torch import nn

class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.branch = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(channels, channels, 3, padding=1),
        )

    def forward(self, x):
        return x + self.branch(x)

print(ResidualBlock(8)(torch.randn(2, 8, 16, 16)).shape)
```
