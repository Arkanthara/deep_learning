## Understand the problem

A normalising flow maps data x into variables z with a simple distribution using an invertible function f. The change-of-variables formula provides an exact density if the Jacobian determinant can be computed. Generation samples z and applies f⁻¹.

## How it works

Real NVP uses affine coupling layers: one part xₐ stays unchanged and determines scale and translation for the other part xᵦ. The Jacobian is triangular, so its log determinant is a sum of logarithmic scales. Networks s and t need not be invertible. Alternating masks allows all coordinates to be transformed across layers.

$$
\log p_X(x)=\log p_Z(f(x))+\log|\det J_f(x)|
$$

## Develop the reasoning

For coupling $y_a=x_a$, $y_b=x_b\odot e^{s(x_a)}+t(x_a)$, xₐ is read directly from yₐ. We can recompute s and t and obtain $x_b=(y_b-t(y_a))\odot e^{-s(y_a)}$. The Jacobian has ones on the unchanged block and exponentials on the other diagonal, hence $\log|\det J|=\sum_j s_j(x_a)$. Complicated derivatives of s and t sit off the diagonal and do not change this triangular determinant. Without alternating masks, some coordinates would always stay unchanged.

## Worked example

With yₐ = xₐ and yᵦ = 2xᵦ + 3, recover xᵦ = (yᵦ−3)/2. The log determinant is ln 2. Omitting this factor would ignore volume expansion in the density.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

x = torch.tensor([[1., 2.]])
a, b = x.chunk(2, dim=1)
s, t = 0.1 * a, 2 * a
y = torch.cat((a, b * s.exp() + t), dim=1)
recovered_b = (y[:, 1:] - t) * (-s).exp()
log_abs_det = s.sum(dim=1)
print(y, recovered_b, log_abs_det)
```

## Understanding check

Two layers have log determinants 0.4 and −0.1. What is the composition’s log determinant, evaluated at the appropriate points?

<details>
<summary>Reveal the worked answer</summary>

It is 0.3: determinants multiply and their logarithms add. The second layer’s determinant is evaluated at the first layer’s output.

</details>
