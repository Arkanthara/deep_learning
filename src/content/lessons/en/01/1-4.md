## Understand the problem

A tensor is a numerical array with multiple axes: a scalar has none, a vector one and a matrix two. The number of axes must not be confused with the number of components of a vector. PyTorch supports elementwise operations, matrix products and indexed slices.

## How it works

To fit a line y ≈ ax + b, minimise the mean squared error. Constructing a matrix X with rows [xₙ, 1] expresses all predictions as one product Xθ. Least squares finds the best approximation even when the points do not lie exactly on a line.

$$
\hat\theta=\arg\min_\theta\frac1N\|X\theta-y\|_2^2
$$

## Develop the reasoning

In matrix notation, $\theta=(a,b)^\top$ and the residual is $r=X\theta-y$. The squared-sum derivative is $2X^\top(X\theta-y)$. Setting it to zero gives the normal equations $X^\top X\theta=X^\top y$. Independent columns give a unique solution. Numerically, solving least squares directly with QR or SVD is preferable to explicitly computing an inverse: forming $X^\top X$ can worsen conditioning. A constant column is needed to learn a nonzero bias.

## Worked example

For (x,y) = (0,1), (1,3), (2,5), parameters a = 2 and b = 1 give zero error. X has shape (3,2), θ has shape (2,1), and Xθ has shape (3,1).

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

x = torch.tensor([0., 1., 2.])
y = torch.tensor([1., 3., 5.])
X = torch.stack((x, torch.ones_like(x)), dim=1)
theta = torch.linalg.lstsq(X, y).solution
print(theta)  # tensor([2., 1.])
print(X @ theta)  # tensor([1., 3., 5.])
```
