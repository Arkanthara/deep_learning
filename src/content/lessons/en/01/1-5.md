## Understand the problem

Shape describes how values are organised, dtype their numerical type and device their computation location. An RGB image batch generally follows the N × C × H × W convention in the course examples. Assigning a meaning to each axis prevents normalisation and reduction mistakes.

## How it works

Broadcasting aligns axes from the right: two sizes are compatible if equal or if one is 1. A singleton dimension therefore applies the same vector to multiple rows without a Python loop. view and reshape change shape; transpose and permute change axis order. These operations are not interchangeable.

$$
(8,3,32,32)-(1,3,1,1)\longrightarrow(8,3,32,32)
$$

## Develop the reasoning

To decide whether two tensors broadcast, right-align their shapes and imagine leading ones on the shorter shape. At every axis, sizes other than 1 must match. The result uses the larger size. Reduction removes an axis unless `keepdim=True`. Thus subtracting each row mean from a matrix often requires a mean of shape (N,1), rather than (N,), which aligns with columns.

## Worked example

To normalise each channel of a batch (8,3,32,32), a mean of shape (1,3,1,1) broadcasts correctly. A vector (3,) would align with width 32 and fail.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch

batch = torch.randn(8, 3, 32, 32)
mean = batch.mean(dim=(0, 2, 3), keepdim=True)
std = batch.std(dim=(0, 2, 3), keepdim=True)
normalised = (batch - mean) / std.clamp_min(1e-6)
print(mean.shape)  # (1, 3, 1, 1)
print(normalised.shape)  # (8, 3, 32, 32)
```

What is the sum shape for tensors (4,1,6) and (3,6)? What about (4,2,6) with (3,6)?
