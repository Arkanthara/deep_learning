## Understand the problem

Semantic segmentation predicts a class at every position. The network must understand global context while locating boundaries precisely. An encoder reduces resolution to extract semantics; a decoder reconstructs a dense score map.

## How it works

FCNs adapt classification networks to spatial outputs. Simple upsampling cannot recover all lost precision: cross-resolution connections combine early detail with deep semantic information. U-Net notably uses concatenation connections between encoder and decoder. Classification loss is applied to annotated pixels.

$$
Z\in\mathbb R^{B\times C\times H\times W},\quad\hat Y_{b,h,w}=\arg\max_c Z_{b,c,h,w}
$$

## Develop the reasoning

A reduced map has a large receptive field but few positions. Interpolation enlarges the grid without recovering precise input-based localisation. Skips therefore bring back high-resolution features. Concatenation adds the channel counts of both levels; a later convolution learns to combine them. Shapes must align and transformations must not misalign masks. Unlabelled pixels should be explicitly ignored in both loss and metrics.

## Worked example

For B = 2 images, C = 5 classes and 32×32 resolution, logits have shape (2,5,32,32). Integer targets have shape (2,32,32); argmax along the class axis gives the predicted mask.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch
from torch import nn

logits = torch.randn(2, 5, 32, 32, requires_grad=True)
target = torch.randint(0, 5, (2, 32, 32))
loss = nn.CrossEntropyLoss()(logits, target)
loss.backward()
segmentation = logits.argmax(dim=1)
print(segmentation.shape)  # (2, 32, 32)
```
