## Understand the problem

Classification networks transform an image into features and then scores. The course follows LeNet, AlexNet, VGG, GoogLeNet, ResNet and other variants. These architectures illustrate choices of depth, width, filter size, channel grouping and spatial reduction.

## How it works

Stacking small filters expands the receptive field with intermediate nonlinearities. A 1×1 convolution mixes channels and can reduce the cost of later filters. Global spatial averaging reduces dependence on a fixed input size. Replacing a fully connected layer with its convolutional equivalent applies the same predictor at multiple positions. Augmentations should preserve label meaning.

$$
C\times H\times W\xrightarrow{\mathrm{global\ average}}C
$$

## Develop the reasoning

To make a dense layer convolutional, retain its weights but reshape them to the C×H×W input map it consumed. A filter of that size produces the same score when there is one valid position; on a larger map it produces multiple scores sharing those weights. This equivalence assumes the same flattening order. Inception uses parallel scales; ResNeXt adds grouped transformations; EfficientNet coordinates depth, width and resolution rather than scaling only one axis.

## Worked example

Two stride-1 3×3 convolutions have a 5×5 receptive field. With C channels throughout and no bias, they use 18C² weights versus 25C² for one 5×5 convolution, and allow an extra activation.

## Understanding check

A Linear layer maps a flattened (8,3,3) feature map to 5 outputs. Which Conv2d performs the same computation on that map?

<details>
<summary>Reveal the worked answer</summary>

Conv2d(8,5,kernel_size=3), without padding, using correctly reshaped weights and the same biases. Output shape is (5,1,1), or five scores.

</details>
