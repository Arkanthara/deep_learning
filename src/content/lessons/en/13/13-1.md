## Understand the problem

A recurrent encoder compressing an entire sentence into one vector imposes a bottleneck. Attention allows the decoder to consult different input representations for each generated word. Reading weights depend on content and the current query rather than solely on a fixed spatial connection.

## How it works

In additive attention for translation, a score a(sᵢ₋₁,hⱼ) compares the decoder state with encoder states. Softmax over source positions yields positive coefficients summing to 1; their weighted average produces context cᵢ. This context helps update the state and predict the next word. The source also presents explicit Neural Turing Machine-style memory: a controller reads and writes with differentiable addressing weights, combining content and location.

$$
\alpha_{ij}=\operatorname{softmax}_j a(s_{i-1},h_j),\qquad c_i=\sum_j\alpha_{ij}h_j
$$

## Develop the reasoning

A weighted read $r=\sum_j\alpha_jm_j$ is differentiable with respect to contents m and scores determining α. The model can therefore learn where to read from the final loss. In writable memory, erase and add operations must also remain differentiable. In translation, additive attention compares the decoder query with each source representation and normalises scores. Normalisation runs over source positions even when target length differs.

## Worked example

For scalar states 2, 4 and 10, weights 0.1, 0.2 and 0.7 produce context 8. The model can shift these weights for the next word rather than retain the same sentence compression.

## Understanding check

A source sentence has 7 tokens and the target 5. What shape is an attention matrix linking each output to the source?
