## Understand the problem

LSTMs and GRUs introduce gates to control memory. An LSTM has a cell state c and an exposed state h. The forget gate modulates old content, the input gate modulates writing and the output gate determines what becomes visible.

## How it works

The additive cell update helps retain information over many steps, particularly when the forget gate stays near 1. A GRU simplifies the structure using one state with update and reset gates. These mechanisms mitigate vanishing gradients without excluding explosions; norm clipping limits the gradient size used. Padded sequences require appropriate lengths or masks.

$$
c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\qquad h_t=o_t\odot\tanh(c_t)
$$

## Develop the reasoning

Sigmoid gates lie between 0 and 1 and modulate elementwise products. The cell proposal generally passes through tanh. Even with a forget gate near 1, gates depend on state and gradient paths remain coupled: long memory is facilitated, not guaranteed. Global clipping computes the norm of all gradients and applies one common factor min(1,τ/||g||). This differs from independently clipping coefficients, which can change direction.

## Worked example

If fₜ = 1 and iₜ = 0, the cell preserves cₜ₋₁ exactly. With gradient norm 10 and threshold 2, global clipping multiplies all gradients by 0.2, preserving their direction.

## Read the code

Run this example in a Python environment with PyTorch. In-browser execution is planned for V2.

```python
import torch
from torch import nn

lstm = nn.LSTM(input_size=6, hidden_size=16, batch_first=True)
x = torch.randn(4, 10, 6)  # batch, time, features
output, (h, c) = lstm(x)
print(output.shape)  # (4, 10, 16)
print(h.shape, c.shape)  # (1, 4, 16), (1, 4, 16)
```
