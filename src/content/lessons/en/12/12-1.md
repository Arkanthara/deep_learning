## Understand the problem

An RNN processes a sequence by updating a hidden state. At each step, the state combines the new input and previous memory. The same parameters are reused at every time step, enabling variable-length inputs with a fixed parameter count.

## How it works

Unrolling through time produces a deep graph, where backpropagation through time sums contributions from repeated uses of the weights. Products of Jacobians can make gradients vanish or explode. A gate mixes the old state with a proposed update, giving memory an additive route. Outputs may be produced at every step or only at sequence end.

$$
h_t=\phi(W_xx_t+W_hh_{t-1}+b),\qquad y_t=\psi(h_t)
$$

## Develop the reasoning

The gradient towards an old state contains products $\prod_t \partial h_t/\partial h_{t-1}$. Norms typically below 1 contract signals while larger norms can amplify them; directions and activations make analysis subtler than one scalar. Truncating backpropagation limits graph length but also prevents some long dependencies contributing gradients. Keeping state between batches can help a continuous sequence; it should be reset when independent sequences begin.

## Worked example

To decide whether a sequence repeats two identical halves, the model must retain information about the first half until the second. Increasing sequence length also lengthens the gradient path.

## Understanding check

Why detach hidden state between segments in truncated backpropagation?

<details>
<summary>Reveal the worked answer</summary>

It preserves its numerical value as context while cutting the graph to previous segments. Computational memory and gradient reach are thereby explicitly limited.
