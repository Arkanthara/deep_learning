## Comprendre le problème

La perte mesure l’erreur sur un exemple. Le risque est son espérance sur la population réelle, généralement inconnue. Pour apprendre, on remplace cette espérance par une moyenne sur les exemples disponibles : le risque empirique. Le modèle est choisi pour rendre cette moyenne petite.

## Le mécanisme

Pour une fonction fixée indépendamment des données, la moyenne empirique est un estimateur sans biais du risque sous échantillonnage i.i.d. Mais après sélection du modèle sur ces mêmes données, cette garantie ne s’applique plus directement. La fonction choisie dépend maintenant de l’échantillon : c’est précisément la difficulté de généralisation.

$$
R(f)=\mathbb{E}[\ell(f,Z)],\qquad\hat R(f)=\frac1N\sum_{n=1}^N\ell(f,z_n)
$$

## Approfondir le raisonnement

Le symbole Z peut désigner un couple (X,Y) en apprentissage supervisé ou seulement X en estimation de densité. Pour une fonction fixée, la linéarité de l’espérance donne E[Σℓ(f,Zₙ)/N] = ΣE[ℓ(f,Zₙ)]/N = R(f). Mais l’opération de minimisation sur les mêmes données sélectionne les fluctuations favorables : E[min R̂] n’est pas min E[R̂]. C’est pourquoi il faut séparer le problème d’optimisation, réduire la perte observée, du problème statistique, prévoir la performance future.

## Exemple pas à pas

Une erreur moyenne de 0 sur dix exemples ne dit rien, à elle seule, sur les prochains exemples. Un prédicteur pourrait mémoriser les dix réponses et se tromper partout ailleurs.

## Exercice de compréhension

Deux modèles ont le même risque réel. Tu choisis celui ayant la plus petite erreur sur un petit échantillon. Cette erreur sélectionnée est-elle une estimation indépendante ?

<details>
<summary>Afficher la correction</summary>

Non. Le choix exploite les fluctuations de cet échantillon. Il faut évaluer le modèle choisi sur un autre échantillon indépendant pour obtenir une mesure qui n’a pas guidé la sélection.

</details>
