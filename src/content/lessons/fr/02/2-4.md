## Comprendre le problème

Les paramètres sont appris sur le jeu d’entraînement. Les hyperparamètres, tels que la profondeur ou le taux d’apprentissage, sont choisis avec le jeu de validation. Le jeu de test doit fournir une estimation finale sur des données qui n’ont pas guidé ces choix.

## Le mécanisme

Consulter le test puis modifier la méthode introduit une boucle d’apprentissage indirecte. Même sans calculer de gradient sur le test, on finit par s’y adapter. Quand les données sont rares, la validation croisée réutilise différents découpages pour la sélection. Les prétraitements appris doivent eux aussi être ajustés uniquement sur les partitions d’entraînement.

$$
\mathcal D_{\mathrm{train}}\cap\mathcal D_{\mathrm{val}}=\varnothing,\quad\mathcal D_{\mathrm{test}}\cap(\mathcal D_{\mathrm{train}}\cup\mathcal D_{\mathrm{val}})=\varnothing
$$

## Approfondir le raisonnement

Le découpage doit refléter l’indépendance réelle. Si plusieurs images viennent du même patient ou plusieurs mesures du même utilisateur, une division aléatoire ligne par ligne peut laisser des quasi-doublons des deux côtés. Un découpage par groupes ou chronologique peut être nécessaire. À l’intérieur d’une validation croisée, toute étape apprise — moyenne, vocabulaire, sélection de variables — doit être recalculée sur le pli d’entraînement. On peut ensuite entraîner le modèle final sur les données de développement avec les choix fixés et ne consulter le test qu’à la fin.

## Exemple pas à pas

Pour choisir parmi trois taux d’apprentissage, on compare les scores de validation, on fixe le choix, puis on mesure le test. Choisir le meilleur taux d’après le test transformerait celui-ci en validation.
