## Comprendre le problème

Un nn.Module décrit une architecture ; une autograd.Function définit une opération avec une dérivée personnalisée. On fournit forward et backward comme méthodes statiques. L’appel passe par apply, qui relie l’opération au graphe de différentiation.

## Le mécanisme

Le contexte sauvegarde les valeurs nécessaires, notamment via save_for_backward. backward reçoit la sensibilité sur la sortie et doit renvoyer une contribution pour chaque entrée, ou None pour une entrée non différentiable. gradcheck compare le résultat à des différences finies ; on utilise généralement des entrées en double précision loin des points non différentiables.

$$
\mathrm{backward}(v)=J_f(x)^\top v
$$

## Approfondir le raisonnement

Le contrat de backward est un produit par la jacobienne transposée. Pour plusieurs entrées, retourner un gradient de même forme pour chacune, dans leur ordre, et None pour les arguments non différentiables. Les valeurs intermédiaires nécessaires doivent être sauvegardées sans mutation ultérieure. `gradcheck` perturbe numériquement chaque entrée et compare les variations ; une petite tolérance, le double et des points réguliers évitent de confondre une erreur d’arrondi ou une non-dérivabilité avec un bug. Les dérivées d’ordre supérieur demandent une implémentation qui conserve elle-même les dépendances utiles.

## Exemple pas à pas

Pour une opération y = x², backward doit renvoyer grad_output × 2x. Renvoyer seulement 2x oublierait la dépendance de la perte aux calculs situés après y.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch

class Square(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x.square()

    @staticmethod
    def backward(ctx, grad_output):
        (x,) = ctx.saved_tensors
        return grad_output * 2 * x

x = torch.randn(3, dtype=torch.double, requires_grad=True)
print(torch.autograd.gradcheck(Square.apply, (x,)))
```
