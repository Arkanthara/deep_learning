## Comprendre le problème

Un modèle personnalisé hérite de nn.Module. Son constructeur initialise les sous-modules et sa méthode forward décrit le calcul. Il faut appeler le constructeur parent pour activer l’enregistrement des paramètres. Utiliser model(x) déclenche aussi les mécanismes de hooks ; appeler forward directement les contourne.

## Le mécanisme

Les sous-modules affectés à des attributs sont enregistrés récursivement. Une liste Python ordinaire n’offre pas cette garantie : utiliser ModuleList ou Sequential. L’optimiseur voit les paramètres enregistrés via model.parameters(). Tant que forward utilise des opérations compatibles avec autograd, il n’est pas nécessaire d’écrire une passe arrière manuelle.

$$
(B,C,H,W)\xrightarrow{\mathrm{Flatten}(1)}(B,CHW)
$$

## Approfondir le raisonnement

L’enregistrement établit une arborescence de sous-modules. Elle sert à énumérer les paramètres, construire les sauvegardes, déplacer les tenseurs et propager les modes train/eval. `nn.Parameter` signale une valeur optimisable ; `register_buffer` convient à un état tensoriel non optimisé, par exemple une constante ou statistique persistante. `ModuleList` enregistre des éléments mais ne définit pas leur calcul : la boucle reste dans forward. `Sequential` définit en plus un enchaînement. Créer de nouvelles couches dans forward recréerait leurs paramètres à chaque appel.

## Exemple pas à pas

Après une sortie convolutionnelle (B,16,7,7), Flatten(start_dim=1) produit (B,784). La couche suivante doit donc accepter 784 caractéristiques, sans aplatir le lot.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

class Classifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.ReLU(), nn.MaxPool2d(2),
            nn.Flatten(start_dim=1),
            nn.Linear(16 * 14 * 14, 10),
        )

    def forward(self, x):
        return self.layers(x)

print(Classifier()(torch.randn(8, 1, 28, 28)).shape)
# torch.Size([8, 10])
```
