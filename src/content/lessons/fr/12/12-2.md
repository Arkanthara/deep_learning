## Comprendre le problème

Les LSTM et GRU introduisent des portes pour contrôler la mémoire. Un LSTM possède un état de cellule c et un état exposé h. La porte d’oubli module l’ancien contenu, la porte d’entrée module l’écriture et la porte de sortie détermine quelle information devient visible.

## Le mécanisme

La mise à jour additive de la cellule facilite la conservation d’une information sur de nombreux pas, particulièrement lorsque la porte d’oubli reste proche de 1. Un GRU simplifie la structure avec un seul état et des portes de mise à jour et de réinitialisation. Ces mécanismes atténuent les gradients évanescents sans exclure les explosions ; le clipping de norme limite alors la taille du gradient utilisé. Les séquences rembourrées nécessitent des longueurs ou masques adaptés.

$$
c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\qquad h_t=o_t\odot\tanh(c_t)
$$

## Approfondir le raisonnement

Les portes sigmoid sont entre 0 et 1 et modulent des produits élément par élément. La proposition de cellule passe généralement par tanh. Même avec une porte d’oubli proche de 1, les portes dépendent de l’état et les chemins de gradient restent couplés : la mémoire longue est facilitée, pas garantie. Pour le clipping global, calculer la norme de tous les gradients puis appliquer un facteur commun min(1,τ/||g||). Cela diffère d’un écrêtage indépendant de chaque coefficient, qui peut changer la direction.

## Exemple pas à pas

Si fₜ = 1 et iₜ = 0, la cellule conserve exactement cₜ₋₁. Avec une norme de gradient 10 et un seuil 2, le clipping global multiplie tous les gradients par 0,2, préservant leur direction.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

lstm = nn.LSTM(input_size=6, hidden_size=16, batch_first=True)
x = torch.randn(4, 10, 6)  # batch, time, features
output, (h, c) = lstm(x)
print(output.shape)  # (4, 10, 16)
print(h.shape, c.shape)  # (1, 4, 16), (1, 4, 16)
```
