## Comprendre le problème

La segmentation sémantique prédit une classe à chaque position. Le réseau doit comprendre le contexte global tout en localisant finement les frontières. Un encodeur réduit la résolution pour extraire la sémantique ; un décodeur reconstruit une carte de scores dense.

## Le mécanisme

Les FCN adaptent des réseaux de classification à des sorties spatiales. Une simple remontée de résolution ne récupère pas toute la précision perdue : les connexions entre résolutions permettent de combiner détails précoces et information sémantique profonde. U-Net utilise notamment des connexions de concaténation entre encodeur et décodeur. La perte de classification est appliquée aux pixels annotés.

$$
Z\in\mathbb R^{B\times C\times H\times W},\quad\hat Y_{b,h,w}=\arg\max_c Z_{b,c,h,w}
$$

## Approfondir le raisonnement

Une carte réduite possède un grand champ récepteur mais peu de positions. L’interpolation agrandit la grille sans inventer une localisation précise issue de l’entrée. Les skips récupèrent donc des caractéristiques de haute résolution. Dans une concaténation, les canaux des deux niveaux s’additionnent en nombre ; une convolution ultérieure apprend à les combiner. Il faut aligner les tailles et éviter un décalage des masques lors des transformations. Les pixels sans annotation doivent être ignorés explicitement dans la perte et les métriques.

## Exemple pas à pas

Pour B = 2 images, C = 5 classes et une résolution 32×32, les logits ont la forme (2,5,32,32). Les cibles entières ont la forme (2,32,32) ; argmax sur l’axe des classes donne le masque prédit.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

logits = torch.randn(2, 5, 32, 32, requires_grad=True)
target = torch.randint(0, 5, (2, 32, 32))
loss = nn.CrossEntropyLoss()(logits, target)
loss.backward()
segmentation = logits.argmax(dim=1)
print(segmentation.shape)  # (2, 32, 32)
```
