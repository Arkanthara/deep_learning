## Comprendre le problème

Le gradient rassemble les dérivées partielles d’une perte par rapport aux paramètres. Il indique la direction de plus forte augmentation locale dans la géométrie euclidienne. Pour diminuer la perte, on effectue un petit déplacement dans la direction opposée.

## Le mécanisme

Le taux d’apprentissage η contrôle la taille du pas. Un pas trop petit ralentit ; un pas trop grand peut osciller ou diverger. L’argument repose sur une approximation locale : une direction descendante ne garantit pas une baisse pour un déplacement arbitrairement grand. Pour les réseaux, la non-convexité empêche de garantir généralement le minimum global.

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta\mathcal L(\theta_t)
$$

## Approfondir le raisonnement

Le développement local $L(\theta+\Delta)\approx L(\theta)+\nabla L(\theta)^\top\Delta$ explique le signe négatif de la mise à jour. Avec $\Delta=-\eta\nabla L$, la variation du premier ordre vaut $-\eta\|\nabla L\|^2$. Les termes d’ordre supérieur peuvent cependant dominer si le pas est trop grand. Pour $L(w)=(w-a)^2$, l’erreur évolue exactement comme $w_{t+1}-a=(1-2\eta)(w_t-a)$. La convergence exige ici $0<\eta<1$ ; le seuil dépend de la courbure de la fonction.

## Exemple pas à pas

Pour L(w) = (w−3)², w = 0 donne un gradient −6. Avec η = 0,1, le prochain w vaut 0,6 et la perte passe de 9 à 5,76.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch

w = torch.tensor(0., requires_grad=True)
for step in range(5):
    loss = (w - 3).square()
    loss.backward()
    with torch.no_grad():
        w -= 0.1 * w.grad
    w.grad = None
    print(step, w.item())
```
