## Comprendre le problème

Sauvegarder un modèle permet de réutiliser ses paramètres sans recommencer l’apprentissage. Un state_dict contient les paramètres et buffers enregistrés. Il est généralement plus flexible qu’une sérialisation de l’objet Python complet, laquelle dépend fortement du code et de la classe utilisés lors de la sauvegarde.

## Le mécanisme

Pour reprendre l’apprentissage, sauvegarder aussi l’état de l’optimiseur et l’étape ou l’époque. Une reprise fidèle peut demander les états du scheduler, du générateur aléatoire et de la mise à l’échelle des gradients. Recréer l’architecture, charger ses poids puis restaurer les états nécessaires. map_location gère le chargement sur un matériel différent ; eval configure le comportement d’inférence mais ne désactive pas à lui seul autograd.

$$
\mathrm{checkpoint}=\{\theta,\ \mathrm{optimizer\ state},\ \mathrm{step},\ldots\}
$$

## Approfondir le raisonnement

Une sauvegarde reproductible doit aussi noter la configuration : dimensions, version des données, normalisation et définition des classes. Pour reprendre exactement une trajectoire, l’ordre des lots et les états aléatoires importent. Pour une simple inférence, les poids et buffers suffisent si l’architecture et le prétraitement sont reconstruits correctement. Charger sur CPU puis déplacer le modèle peut faciliter la portabilité. Les fichiers sérialisés doivent provenir d’une source fiable ; l’exemple utilise explicitement `weights_only=True` et un dictionnaire d’états, sans sérialiser arbitrairement une classe Python complète.

## Exemple pas à pas

Adam conserve des moyennes de gradients et de gradients au carré. Recharger seulement les poids puis créer un Adam neuf peut changer les prochaines mises à jour, même avec le même prochain mini-lot.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

model = nn.Linear(4, 2)
optimizer = torch.optim.Adam(model.parameters())
torch.save({
    "model": model.state_dict(),
    "optimizer": optimizer.state_dict(),
    "epoch": 0,
}, "checkpoint.pt")
checkpoint = torch.load("checkpoint.pt", map_location="cpu", weights_only=True)
model.load_state_dict(checkpoint["model"])
optimizer.load_state_dict(checkpoint["optimizer"])
model.eval()
```
