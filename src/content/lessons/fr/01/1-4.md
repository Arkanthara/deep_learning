## Comprendre le problème

Un tenseur est un tableau numérique à plusieurs axes : scalaire sans axe, vecteur avec un axe, matrice avec deux. Le nombre d’axes ne doit pas être confondu avec le nombre de composantes d’un vecteur. PyTorch permet des opérations élément par élément, des produits matriciels et des découpages par indices.

## Le mécanisme

Pour ajuster une droite y ≈ ax + b, on minimise la moyenne des erreurs quadratiques. Construire une matrice X dont les lignes sont [xₙ, 1] permet d’écrire toutes les prédictions en un produit Xθ. La résolution par moindres carrés cherche la meilleure approximation même lorsque les points ne sont pas exactement alignés.

$$
\hat\theta=\arg\min_\theta\frac1N\|X\theta-y\|_2^2
$$

## Approfondir le raisonnement

En notation matricielle, $\theta=(a,b)^\top$ et le résidu est $r=X\theta-y$. La dérivée de la somme quadratique vaut $2X^\top(X\theta-y)$. Annuler ce gradient donne les équations normales $X^\top X\theta=X^\top y$. Si les colonnes sont indépendantes, la solution est unique. Numériquement, résoudre directement les moindres carrés par QR ou SVD est préférable au calcul explicite d’un inverse : former $X^\top X$ peut aggraver le conditionnement. Une colonne constante est nécessaire pour apprendre un biais non nul.

## Exemple pas à pas

Pour (x,y) = (0,1), (1,3), (2,5), les paramètres a = 2 et b = 1 donnent une erreur nulle. X a la forme (3,2), θ la forme (2,1), et Xθ la forme (3,1).

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch

x = torch.tensor([0., 1., 2.])
y = torch.tensor([1., 3., 5.])
X = torch.stack((x, torch.ones_like(x)), dim=1)
theta = torch.linalg.lstsq(X, y).solution
print(theta)  # tensor([2., 1.])
print(X @ theta)  # tensor([1., 3., 5.])
```
