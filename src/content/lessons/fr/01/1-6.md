## Comprendre le problème

Un tenseur combine un stockage linéaire, une forme, un décalage initial et des strides. Le stride d’un axe indique de combien d’éléments avancer dans le stockage quand cet indice augmente de un. Plusieurs tenseurs peuvent ainsi partager les mêmes valeurs physiques tout en les présentant différemment.

## Le mécanisme

Une transposition peut échanger les strides sans copier les données. Cette vue peut devenir non contiguë : view ne peut pas toujours l’aplatir. contiguous produit un stockage contigu si nécessaire ; reshape renvoie une vue lorsque c’est possible et peut sinon copier. Un stride nul permet de répéter logiquement une valeur, comme dans expand.

$$
\mathrm{position}(i)=\mathrm{offset}+\sum_k i_k\,\mathrm{stride}_k
$$

## Approfondir le raisonnement

Un tenseur contigu (3,4) possède typiquement les strides (4,1) : parcourir une ligne avance d’une valeur et changer de ligne de quatre. Sa transposée a forme (4,3) et strides (1,4). Les éléments sont les mêmes mais l’ordre de lecture a changé. La contiguïté n’est donc pas une propriété des valeurs ; c’est une propriété de leur organisation. `expand` peut donner un stride nul et plusieurs indices désignent alors le même élément : une écriture arbitraire dans cette vue peut être ambiguë.

## Exemple pas à pas

Avec offset = 5 et strides = (4,1), l’élément [2,1] se trouve à la position 5 + 2×4 + 1 = 14. Modifier une vue peut modifier le tenseur d’origine ; clone crée une copie indépendante.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch

x = torch.arange(12).reshape(3, 4)
y = x.t()
print(x.stride(), y.stride())  # (4, 1), (1, 4)
print(y.is_contiguous())  # False
flat = y.reshape(-1)  # may allocate a copy
independent = y.clone()
```

## Exercice de compréhension

Une matrice contiguë (2,3) contient [0,1,2] puis [3,4,5]. Quel ordre donne l’aplatissement de sa transposée ?

<details>
<summary>Afficher la correction</summary>

La transposée a les lignes [0,3], [1,4], [2,5], donc l’ordre est [0,3,1,4,2,5]. Cet ordre nécessite généralement une réorganisation du stockage pour une représentation 1D contiguë.
