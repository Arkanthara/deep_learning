## Comprendre le problème

Pour savoir quelles régions influencent une prédiction, on peut masquer des zones et mesurer le changement de score. Cette analyse d’occlusion est intuitive mais coûteuse et dépend du masque choisi. Une autre approche calcule le gradient d’un score de classe par rapport aux pixels : il indique une sensibilité locale.

## Le mécanisme

SmoothGrad moyenne les gradients d’entrées légèrement bruitées pour réduire certaines irrégularités. Les visualisations de type deconvolution et guided backpropagation changent la règle de propagation à travers ReLU ; elles ne représentent donc pas le gradient ordinaire. Grad-CAM pondère les cartes d’une couche convolutionnelle par la moyenne spatiale de leurs gradients pour construire une carte grossière liée à une classe.

$$
\alpha_k^c=\frac1{HW}\sum_{i,j}\frac{\partial s_c}{\partial A_{ij}^k},\qquad L^c=\operatorname{ReLU}\!\left(\sum_k\alpha_k^c A^k\right)
$$

## Approfondir le raisonnement

Pour une perturbation petite δ, le gradient justifie l’approximation $s_c(x+\delta)-s_c(x)\approx\nabla_xs_c(x)^\top\delta$. Un grand coefficient indique une variation locale possible, pas nécessairement la présence d’un concept. Grad-CAM effectue cette analyse dans une couche spatiale choisie ; sa résolution dépend de celle de la carte. Une carte trop profonde peut être grossière, une carte précoce moins sémantique. Pour comparer des méthodes, garder les mêmes entrées, cibles et normalisations et vérifier l’effet de perturbations effectivement appliquées.

## Exemple pas à pas

Pour deux cartes A₁ et A₂, si les poids de gradient sont 0,7 et −0,2, la carte Grad-CAM est ReLU(0,7A₁−0,2A₂), puis elle peut être agrandie pour la superposer à l’image.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

model = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 2))
model.eval()
x = torch.randn(1, 4, requires_grad=True)
score = model(x)[0, 1]
(gradient,) = torch.autograd.grad(score, x)
print(gradient)  # local sensitivity of class 1 to the input
```
