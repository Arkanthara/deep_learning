## Comprendre le problème

Un VAE définit un modèle génératif : tirer z selon un a priori, puis x selon un décodeur probabiliste pθ(x|z). La vraisemblance pθ(x) exige une intégration souvent difficile. Un encodeur qφ(z|x) approxime le posterior et permet d’optimiser une borne inférieure, l’ELBO.

## Le mécanisme

L’ELBO combine une reconstruction probabiliste attendue et une divergence KL entre posterior approché et a priori. La KL relie les codes à une distribution dans laquelle on saura échantillonner. Avec un encodeur gaussien diagonal, la reparamétrisation z = μ + σ⊙ε sépare le bruit aléatoire des paramètres différentiables. Maximiser l’ELBO revient à minimiser son opposé, en échantillonnant typiquement un z par exemple.

$$
\mathrm{ELBO}(x)=\mathbb E_{q_\phi(z|x)}[\log p_\theta(x|z)]-D_{KL}(q_\phi(z|x)\|p(z))
$$

## Approfondir le raisonnement

L’identité $\log p_\theta(x)=\mathrm{ELBO}(x)+D_{KL}(q_\phi(z|x)\|p_\theta(z|x))$ montre pourquoi l’ELBO est une borne : la KL restante est positive. Pour un posterior diagonal gaussien et un a priori normal standard, sa pénalité est $\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2)$. Le terme de reconstruction dépend du décodeur choisi : gaussien à variance fixée donne une erreur quadratique à une échelle près ; Bernoulli donne une log-vraisemblance binaire. Il faut équilibrer des sommes et moyennes cohérentes sur pixels, dimensions latentes et lots.

## Exemple pas à pas

Pour q = N(0,I) et p = N(0,I), la KL vaut zéro. Si μ s’éloigne de zéro sans améliorer la reconstruction, la pénalité augmente. log_var représente log σ² ; il faut donc exp(log_var/2) pour obtenir σ.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch

mu = torch.zeros(4, 8, requires_grad=True)
log_var = torch.zeros(4, 8, requires_grad=True)
eps = torch.randn_like(mu)
z = mu + torch.exp(0.5 * log_var) * eps
kl_per_sample = 0.5 * (
    mu.square() + log_var.exp() - 1 - log_var
).sum(dim=1)
print(z.shape, kl_per_sample)
```
