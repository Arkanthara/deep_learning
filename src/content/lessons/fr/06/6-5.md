## Comprendre le problème

Un bloc résiduel apprend une correction F(x) ajoutée à l’entrée. Il peut approcher l’identité en rendant simplement cette correction petite. L’idée prolonge les highway networks, où une porte contrôlait la quantité de signal transformé ou transmis directement.

## Le mécanisme

La dérivée du bloc contient un terme identité, offrant un chemin direct au signal et au gradient. Les deux branches doivent avoir des formes compatibles ; un changement de résolution ou de canaux peut demander une projection, souvent une convolution 1×1. Les variantes préactivées déplacent normalisation et activation pour préserver un chemin identité plus direct. La profondeur stochastique supprime temporairement des branches résiduelles.

$$
y=x+F(x),\qquad\frac{\partial y}{\partial x}=I+J_F(x)
$$

## Approfondir le raisonnement

Pour une sensibilité g reçue sur y=x+F(x), la sensibilité de x vaut $g+J_F(x)^\top g$. Si F a une petite dérivée, la contribution directe reste proche de g. Une projection P remplace l’identité quand les dimensions diffèrent, donnant y=Px+F(x) et gradient $P^\top g+J_F^\top g$. Ce raccourci n’est alors plus une identité exacte. L’addition des branches résiduelles se distingue d’une concaténation U-Net : une concaténation conserve les canaux séparés et modifie leur nombre.

## Exemple pas à pas

Si un bloc doit conserver une bonne représentation existante, apprendre F(x) ≈ 0 est naturel. Si l’entrée possède 16 canaux et F(x) en produit 32, l’addition exige d’adapter la branche de raccourci.

## Lire le code

Exemple à exécuter dans un environnement Python avec PyTorch. L’exécution dans le navigateur est prévue pour la V2.

```python
import torch
from torch import nn

class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.branch = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(channels, channels, 3, padding=1),
        )

    def forward(self, x):
        return x + self.branch(x)

print(ResidualBlock(8)(torch.randn(2, 8, 16, 16)).shape)
```
